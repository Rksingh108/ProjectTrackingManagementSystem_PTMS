# PTMS
PROJECT TRACKING MANAGEMENT SYSTEM (PTMS)

Project Abstract

Managing multiple projects across teams can be difficult without a centralized system. PTMS provides an enterprise-level platform to plan, track, and manage projects, tasks, team members, deadlines, and overall project progress in one place. The application allows project managers to create projects, assign tasks to ticketManagements, set priorities and deadlines, and monitor task status and project milestones. Team members can view their assigned work, update task progress, and collaborate with other team members. Project managers can monitor project timelines, identify delays, track team performance, and manage project resources. Administrators can manage users, roles, projects, and system configurations. The system also provides dashboards, reports, notifications, and progress tracking to give stakeholders a clear view of project health and performance. Role-based access control ensures that administrators, project managers, team members, and other stakeholders can access only the features and information relevant to their responsibilities. The application is designed using enterprise development practices with a scalable backend, secure authentication, database management, REST APIs, and modular architecture.

Overall Business Workflow

•	Admin creates users and assigns roles (Project Manager, Team Lead, or Employee).
•	Project Manager creates a project with its name, requirements, priority, and deadline.
•	Project Manager assigns the project to a Team Lead.
•	Team Lead creates tasks under the project and assigns them to Employees, setting deadlines.
•	Employee works on the assigned task and updates status, progress, and comments.
•	Employee submits the task when the work is finished.
•	Team Lead reviews the submitted task and approves or rejects it.
•	If rejected, the task goes back to the Employee with remarks,if approved, it counts toward project progress.
•	Project Manager checks overall project progress based on approved tasks.
•	Project Manager approves project completion once all tasks are approved.
Approval Flow: Manager creates project → Team Lead assigns task → Employee completes task → Team Lead reviews and approves/rejects → Manager checks overall progress → Manager approves project completion
